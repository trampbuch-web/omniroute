# «Интересный факт»

Вертикальные ролики для TikTok (9:16, чуть больше минуты): Тимофей сидит в студии за столом,
цепляющая фраза в первые секунды, 5 фактов (+ бонус), карточки «ФАКТ №N», джамп-каты на лицо,
полоса прогресса сверху, крупные субтитры по словам, губы по Rhubarb, призыв в комментарии в конце.

Собирается тем же движком, что «В центре Родины»: `python3 ../v-centre-rodiny/build.py <папка>`.
В `episode.json`: `"brand": "ИНТЕРЕСНЫЙ ФАКТ"`, `"slug": "interesny-fakt"`, `"punch": true`,
`"max_len"`, сегменты с `"loc": "studio", "action": "talk"`.
