# «Тень власти»

Политический анимационный триллер для TikTok, 60–75 с, раз в два дня. Сезон 1 — «Комната без окон»
(см. `CONCEPT.md`). Ведущий и рассказчик — Тимофей Беспартийный.

- `<серия>/episode.json` (папки `s01e02`, …): `title`, `season`, `episode`, `voices` (синтетические голоса для
  цитат: теги OmniVoice вроде `"male, elderly, low pitch"`), `sources`, `scenes`. У сцены: `type`, `stamp`
  (`ПОДТВЕРЖДЕНО` / `ВЕРСИЯ` / `РЕКОНСТРУКЦИЯ` / произвольная), `src` (источник и дата), `place`, `lines` —
  `["N", текст]` для рассказчика или `["Q1", текст, "ИМЯ"]` для цитаты.
- Типы сцен (`scenes.js`): `chairs`, `map` (`big`), `yalta`, `leader` (`who`: putin | trump | xi), `empty`,
  `folder` (`items`), `door` (`big`). Новая локация = новая функция в `SCENES`.
- `python3 build.py <серия>` — озвучка (OmniVoice, кэш по тексту), рендер, музыка и удары на склейках.
  `--frames 5,20` — кадры для проверки. `node preview.mjs <серия> [секунда]` — обложка.
- Озвучка: `python3 -m venv --system-site-packages ~/.cache/ov-venv && ~/.cache/ov-venv/bin/pip install omnivoice`.
  На процессоре одна фраза считается около минуты.
- Голос рассказчика — голос владельца канала, клонирован с его согласия из `voice/narrator-ref.wav` (с 17.11 — из его ролика «твой друг списывает»; прежний образец — `narrator-ref-v1.wav`).
  Голоса других реальных людей не клонируются: цитаты читают синтетические голоса с подписью «ЦИТАТА».
- Правила содержания: начало без приветствий, с события или противоречия; новый кадр каждые 3–6 с; только
  проверенные факты с источником и датой; цитаты политиков — только публичные и дословные; спорное помечается
  как версия; разные стороны, без пропаганды.
