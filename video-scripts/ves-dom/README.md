# «Весь дом в курсе»

Вертикальный ролик (9:16, 45–55 с): пятиэтажка в разрезе. Тимофей едет на лифте и на каждом этаже
рассказывает жильцу одну новость дня (источник — t.me/s/rian_ru), жилец отвечает одной репликой.
В конце камера поднимается на крышу к коту Барсику и отъезжает на общий план — ролик зациклен.

- Жильцы (код в сценарии): 1 этаж — баба Зина `Z`, 2 — дядя Толя `T`, 3 — блогер Кристина `K`,
  4 — айтишник Гоша `G`, 5 — школьник Петя `P`, 6 — финансист Марина Викторовна `M` (деньги, банки, налоги,
  ипотека), крыша — кот Барсик `B`. Ведущий — `H`.
- Гости: у остановки можно указать `"guest": "D" | "U" | "A"` — тогда на этом этаже вместо жильца отвечает гость
  (жилец стоит рядом): дед Михалыч `D` (дача, огород, «вот в наше время»), участковый Семёныч `U` (законы, штрафы,
  мошенники), студентка Аня `A` (вузы, стипендии, работа, соцсети). Каждый гость — не больше одного раза за выпуск.
- `<дата>/episode.json`: `hook` (две строки на обложке), `hook_say` (первая фраза), `stops` — этажи по
  порядку снизу вверх (можно пропускать этажи), последний — `"floor": "roof"`; у этажа `card`
  (`tag`, `big`, `small`) и `lines`. У крыши `card.meow` — «перевод» мяуканья.
- `python3 build.py <дата>` — озвучка, тайминги, губы (Rhubarb), рендер, звуки лифта и музыка.
  `--frames 0.3,5,20` — только кадры для проверки. `node preview.mjs <дата>` — обложка 1080×1920.
- `house.js` рисует дом, квартиры и жильцов; `dom.html` — камера и анимация.
- Реплики короткие: ведущий — одна фраза до ~4 с, жилец — до ~3 с. Голос ведущего — клон OmniVoice (см. ниже).
- Сервис голосов иногда не отвечает: повторить сборку через минуту (готовые реплики не переозвучиваются).
- Реклама: с 21.11 выпуски без рекламы. Полноэкранный баннер LuxerVPN (`assets/banner.mp4`) вставляется только
  по `"ad": true` в `episode.json` — после средней остановки (+3,5 с); тогда в описании строка про рекламу и `#luxerpvn`.
- Голос ведущего — голос владельца канала (клон OmniVoice с его согласия, образец общий с «Тенью власти»:
  `../ten-vlasti/voice/narrator-ref.wav`); нужен `~/.cache/ov-venv` (см. README «Тени власти»). Остальные — edge-tts.
