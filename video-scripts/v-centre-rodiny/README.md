# «В центре Родины»

Вечерний вертикальный ролик (9:16, ≤ 60 с): Тимофей с микрофоном гуляет по нарисованному
вечернему центру Москвы и пересказывает главное за день из t.me/rian_ru (веб-версия: t.me/s/rian_ru).

- `<дата>/episode.json` — выпуск: сегменты с локацией (`redsquare`, `street`, `arbat`, `cafe`,
  `restaurant`, `car`), действием (`walk`, `interview`, `coffee`, `eat`, `drive`), подписью места,
  карточкой с цифрой/датой и репликами (`H` — Тимофей, `P` — прохожая).
- `python3 build.py <дата>` — озвучка с таймингом слов, синхронизация губ по громкости голоса,
  субтитры по словам, рендер и музыка. `--frames 5,20,40` — только скриншоты для проверки.
- Локации рисует `scenes.js` (окна и огни меняются от даты), ведущий — из `../midterms-animation.html`.
- Губы — по Rhubarb Lip Sync (`../lipsync.py`, скачивается сам).
- Превью: `python3 build.py <дата> --frames 1`, затем `node preview.mjs <дата> <секунда> "<дата · вечерний выпуск>" "<заголовок>" "тег|тег|тег"`.
- Нужно: `pip install edge-tts numpy`, ffmpeg, Playwright с Chromium.
